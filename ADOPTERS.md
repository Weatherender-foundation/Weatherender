# Adopters

This page records organizations and projects that publicly use, evaluate, or integrate **Weatherender** with permission. It is intended to help prospective users understand how the project is used in practice.

## Public adopters

No public adopters have been listed yet.

The live demo at [weather-7icc.onrender.com](https://weather-7icc.onrender.com/) is maintained by the project and is not an independent adopter.

## How to be listed

To request an entry, open an issue or pull request with:

- the name of the organization or project;
- a short, accurate description of how Weatherender is used;
- a public URL, if one is available; and
- the name or handle of a representative who approved the listing.

A listing is optional, does not imply endorsement, and may be removed at the request of the listed party. The maintainer may decline entries that are inaccurate, misleading, unlawful, or inconsistent with the [Code of Conduct](CODE_OF_CONDUCT.md).
