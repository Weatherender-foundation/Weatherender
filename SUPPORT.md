# Support

Need help with **Weatherender**?

## How to get support

1. **Documentation**
   Start with the [README](README.md) and the docs in the [`docs/`](docs/) folder:
   - [Architecture](docs/ARCHITECTURE.md)
   - [API Reference](docs/API.md)
   - [Deployment](docs/DEPLOYMENT.md)
   - [Performance testing](docs/PERFORMANCE.md)

2. **GitHub Issues**
   - Bug reports → open an issue
   - Feature requests → open an issue
   - Questions → open an issue or start a Discussion

3. **Direct contact**
   - Email: [lehacomp16@gmail.com](mailto:lehacomp16@gmail.com)
   - Telegram: [@LyapinAlexey](https://t.me/LyapinAlexey)

## What is **not** supported

- Commercial usage without a commercial license (see [LICENSE](LICENSE))
- Private support for production systems unless you have an explicit agreement
- Urgent production incidents on the free-tier demo instance (`weather-7icc.onrender.com`)

## Response time

We aim to respond to issues and security reports within **48 hours**.
Pull requests are usually reviewed within a few days.
